# Quantitative Research

Hi there! Thanks for viewing my personal research repository.

## About Me
I am wee kiang specializing in equity analysis and quantitative finance. My research and professional focus heavily involve algorithmic trading, machine learning, and options trading. 

I primarily develop in Python and R, leveraging quantitative libraries like `cvxpy` and `pypfopt` to build out strategy backtests, conduct systematic research, and optimize portfolios.

## About This Repository
This repository serves as a workspace for my personal quantitative research projects, strategy backtesting, and algorithmic modeling. It contains a collection of Jupyter Notebooks exploring various quantitative strategies, including:

*   **Machine Learning Applications:** Implementing Neural Networks and Random Forests (with feature importance) for factor-based investing.
*   **Momentum Strategies:** Exploring 12-month/1-month momentum factors and applying them to indices like the S&P 500 using Sharadar data.
*   **Algorithmic Stock & Pair Selection:** AI-driven stock selection systems (e.g., for the NQ100) and pair selection strategies utilizing Zipline.
*   **Fundamental & Classic Strategies:** Quantitative implementations of traditional approaches like the Magic Formula, alongside baseline buy-and-hold benchmarks.
